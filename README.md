## Tech Stack

Handwritten from scratch, zero frameworks:

- **Backend**: plain PHP (no framework), Markdown files as the article store
- **Frontend**: vanilla HTML/CSS/JS, Canvas particle ocean + Web Audio API music visualization
- **Design**: deep-sea Gura theme, HUD sci-fi styling, dark/light themes
- **Environment**: Laragon (Windows)

## Features

- 📝 Markdown article system (front-matter parsing, tag filtering, search)
- 🎵 Local music player (synced LRC lyrics, cover extraction, three play modes)
- 🌌 Canvas particle ocean visualization (Web Audio spectrum reactive)
- 💬 Login-gated comment system (3-level nesting)
- 🌓 Dark/light theme switcher
- 📡 RSS feed
- ✏️ Built-in editors (articles + projects)
- 📱 Responsive design

## Run Locally

```bash
# Requires Laragon or any PHP environment
```
