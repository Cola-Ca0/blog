> 深海之下，别有洞天 — Cola_CaO

杭州师范大学 2026 级，计算机科学与技术，研究网络空间安全方向。CTF + SRC 漏洞挖掘路线。这个博客是我的个人知识基地——安静、专注、记录每一段探索的航迹。

---

## 技术栈

纯手写，无框架：

- **后端**：PHP（无框架），Markdown 文件作为文章存储
- **前端**：原生 HTML/CSS/JS，Canvas 粒子海洋 + Web Audio API 音乐可视化
- **设计**：深海 Gura 主题，HUD 科幻界面风格，深色/浅色双主题
- **运行环境**：Laragon（Windows）

## 功能

- 📝 Markdown 文章系统（front matter 解析、标签筛选、搜索）
- 🎵 本地音乐播放器（LRC 歌词同步、封面提取、三种播放模式）
- 🌌 Canvas 粒子海洋可视化（Web Audio 频谱联动）
- 💬 登录门控评论系统（3 层嵌套）
- 🌓 深色/浅色主题切换
- 📡 RSS 订阅
- ✏️ 内置编辑器（文章 + 项目）
- 📱 响应式设计

## 本地运行

```bash
# 需要 Laragon 或任意 PHP 环境
git clone https://github.com/Cola-Ca0/blog.git
# 放到 www 目录下，访问 http://localhost/blog/
```
