Local Music Player - Usage
===========================

1. Drop your .mp3 files here
2. (Optional) Drop matching .lrc lyrics files with the SAME name
   Example: song.mp3 + song.lrc

LRC Format:
   [00:12.34]First line of lyrics
   [00:15.67]Second line of lyrics
   ...

The player auto-scans this folder on page load.
Lyrics sync in real-time as the song plays.
