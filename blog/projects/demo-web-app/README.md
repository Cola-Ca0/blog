# Demo Web App

A simple PHP web application demonstrating login, session management, and database CRUD.

## Features
- User registration & login (bcrypt hashing)
- Session management with cookies
- Math CAPTCHA verification
- JSON-based data storage

## Tech Stack
- PHP 8+
- JSON file storage
- Vanilla CSS/JS frontend

## Setup
1. Clone into Laragon `www/` directory
2. Ensure PHP 8+ is running
3. Access via `http://localhost/demo-web-app/`
