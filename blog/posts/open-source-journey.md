## 第一次提交 PR

还记得第一个 Pull Request 被 merge 时的那种兴奋：就像在深海中第一次发现发光的生物，那种"我的代码被世界看到了"的感觉无法言喻。

那是一个很小的修改：文档里的一处拼写错误。但正是这个小开始，让我理解了开源的工作流：Fork、Branch、Commit、PR、Review、Merge。

## 参与社区

开源不仅仅是代码。回答问题、写文档、提 issue 都是贡献。社区的温暖是最意外的收获。

在一个 issue 讨论中，我提了一个安全相关的建议，结果维护者不仅采纳了，还私信感谢了我。**这就是开源的力量**：陌生人因为共同的目标协作，彼此成就。

## 从使用者到贡献者

从"这个库怎么用"到"这个 bug 我来修"，心态的转变是最重要的。不再把自己当成外人，而是项目的一部分。
